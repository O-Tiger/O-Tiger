## How I work

- **Modular design.** A multi-module Maven monolith (API / core / integrations) with ADRs, instead of premature microservices.
- **Security basics done right.** Input validation with Zod, per-route rate limiting, restricted CORS, Helmet and JWT in httpOnly cookies.
- **CI that catches mistakes.** GitHub Actions running lint, tests (Jest and supertest) and build on every push and PR, plus semantic versioning and a changelog.
- **Payments handled carefully.** Stripe and MercadoPago (PIX) checkout with webhooks and protection against duplicate payment records.
